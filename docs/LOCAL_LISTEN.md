# 本地互助听歌

本地互助听歌用于让同一套程序中已登录的网易云账号互相播放音乐人歌曲。账号、歌曲、调度和统计全部保存在本机，不会上传到第三方互助服务。

> 本功能仅供学习与个人账号管理。请合理设置次数和播放频率，并自行承担平台规则及账号风控风险。

## 工作方式

一个本地互助池由两类账号组成：

- **音乐人账号**：正常执行签到、发布动态和 VIP 等音乐人任务；开启本地互助并填写歌曲 ID 后，可以成为被播放目标。
- **普通播放账号**：只负责播放本地音乐人账号的目标；不会排程或手动执行音乐人任务，也不会成为被播放目标。

账号角色在新增账号、登录之前选择，后续可以在账号的「编辑」窗口中修改。现有账号升级后默认保持为音乐人角色。

普通播放账号会自动加入本地互助。音乐人账号是否参与互助由用户单独控制；没有开启互助或没有填写歌曲 ID 的音乐人账号不会进入目标池。

## 配置步骤

### 1. 添加账号并选择角色

在「新增账号」窗口中填写登录信息，并选择：

- `音乐人账号（执行音乐人任务，可被互助）`
- `普通播放账号（只帮助其他音乐人播放）`

保存后完成登录。普通账号使用网易云通用登录态，不要求其本身是音乐人。

### 2. 配置音乐人歌曲

打开音乐人账号的「编辑」窗口：

1. 开启「加入本机账号互助」。
2. 填写希望被播放的歌曲 ID。
3. 保存账号。

支持填写多个目标，使用逗号、中文逗号、分号、空格或换行分隔，例如：

```text
2742170333
2742143551, 2742199999
```

相同 ID 会自动去重。当前也兼容 `album:专辑ID` 格式，但专辑页面实际以当前播放器中的单首歌曲达到阈值作为一次完成。

### 3. 设置执行频率

在「全局设置 → 本地账号互助听歌」中配置：

| 设置 | 默认值 | 说明 |
|---|---:|---|
| 每日开始时间 | `09:30` | 每天自动开始本地互助的时间 |
| 每账号每日最多帮助 | `25` | 单个执行账号每天最多成功播放次数；设为 `0` 表示当天不执行 |
| 每账号每月最多帮助 | `650` | 单个执行账号每月最多成功播放次数；设为 `0` 表示当月不执行 |
| 每首播放比例 | `34%` | 可设置 `34%～100%`；达到比例后额外播放 5 秒，最多到歌曲结束 |

每日和月度上限限制的是每个执行账号的成功帮助次数，不保证某一首歌曲一定获得相同次数。实际被播放数量取决于参与账号数、歌曲数、登录状态和播放成功率。

## 分配与播放规则

每个执行账号只会领取满足以下条件的目标：

- 位于同一个本地 SQLite 数据库；
- 账号总开关为启用；
- 角色为音乐人；
- 已开启本地互助；
- 至少配置了一个有效歌曲 ID；
- 不是当前执行账号自己。

目标按照当天被帮助次数从少到多分配。多个音乐人账号之间轮换；同一音乐人的多个歌曲 ID 也会优先选择当天播放次数较少的歌曲。因此当天允许重复播放，但会尽量保持账号和歌曲之间均衡。

一次批量任务只启动一个持久化浏览器上下文：

1. 使用执行账号的本地登录 profile 校验网易云会话。
2. 打开第一首歌曲并开始播放。
3. 达到“设置比例 + 5 秒”的阈值后记录成功。
4. 在同一个浏览器上下文中新开标签页。
5. 关闭上一标签页并执行下一首，不重复启动 Chromium。

设置为 `100%` 时播放到歌曲结束，不额外等待超过歌曲总时长。

## 自动与手动执行

- **自动执行**：每天到设置时间后，为每个参与账号执行当天/月度剩余配额。
- **手动执行**：点击账号「执行」，勾选「本地互助听歌」。手动执行同样受每日和月度上限约束，并会批量执行剩余配额。
- **持续播放**：点击「一键播放」，全部启用账号并发循环播放；单账号失败后 3 秒自动重启，直到点击「停止播放」。
- **普通播放账号**：执行弹窗只允许选择本地互助听歌。

不同账号使用独立 profile 并发运行；同一账号的浏览器任务自动串行，避免多个任务同时占用同一个 profile。

## 强制停止

运行时点击「强制停止」会结束 Chromium 进程，并通知对应任务线程退出。播放循环通常会在两秒内识别停止：

```text
手动强制停止……
已强制停止浏览器进程
本地互助已停止：歌曲ID
```

未开始的剩余歌曲不会被记为播放失败，也不会继续输出 `进度 0/0`。

## 统计与历史日志

账号列表显示：

- **帮助**：当前账号今天成功播放其他音乐人歌曲的次数。
- **被帮助**：当前音乐人账号的歌曲今天被其他本地账号成功播放的次数。

播放分配及结果保存在 SQLite 的 `local_listen_runs` 表。浏览器实时日志和状态保存在 `task_logs` 表：

- 默认保留 3 天；
- 可在全局设置中修改保留天数；
- 每天凌晨 `03:15` 自动清理；
- 点击账号的「日志」可以随时查看；
- 调试截图可以从历史日志中的「查看截图」链接直接预览。

二维码不会写入数据库。文件级 `app.log` 仍会轮转保存，用于服务排障。

## 数据与安全边界

本地互助不会调用第三方互助 API，也不会向外部互助服务器发送：

- 手机号或手机号 MD5；
- 密码、Cookie 或浏览器 profile；
- 歌曲 ID、账号角色或互助统计。

网易云网页播放本身仍会正常访问网易云服务。所有本地账号都由同一位部署者管理，因此不依赖其他开源客户端诚实上报，也不存在公共任务池向本机账号下发恶意目标的问题。

## 常见问题

### 一直显示进度 `0/0`

通常表示页面尚未加载出播放器、歌曲不可播放、登录态失效或页面结构发生变化。可点击「日志」查看详细记录，并检查调试截图。强制停止后若仍持续输出 `0/0`，请确认服务已经重启并运行最新代码。

### 密码错误却进入二次验证

当前版本会监听 `/weapi/login/cellphone`。返回非 `200`（例如账号或密码错误）时会立即终止，并同时使用页面错误文案兜底。修改代码后需要重启服务才能生效。

### 为什么没有达到 650 次

`650` 是单个执行账号的月度帮助上限，不是平台结果保证。还需要考虑：

- 可用普通播放账号数量；
- 每日上限与本月剩余天数；
- 每首歌曲时长和播放比例；
- Cookie 是否有效；
- 歌曲是否能在网页端正常播放；
- 任务是否被手动停止。

### 修改角色后什么时候生效

保存账号后会立即重建调度。切换为普通播放角色后不再排程音乐人任务，并自动加入本地互助；切换为音乐人后可以配置是否参与互助及歌曲目标。
